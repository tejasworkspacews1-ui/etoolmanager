# Assets

This directory contains visual assets for the **eToolManager** project.

## Contents

| File | Purpose |
|------|---------|
| `logo.png` | Project logo (placeholder) |
| `screenshots/` | Terminal screenshots for the README |

## Logo

The `logo.png` file is a placeholder. Replace it with a professional logo
for the project. Suggested design:

- **Name:** eToolManager
- **Tagline:** Automated Tool Manager for eSim
- **Colors:** Blue/cyan (matching the CLI theme)
- **Icon:** A wrench + circuit board motif

## Screenshots

Capture the following terminal outputs and save them in `screenshots/`:

| File | Command |
|------|---------|
| `system.png` | `etoolmanager system` |
| `status.png` | `etoolmanager status` |
| `check.png` | `etoolmanager check` |
| `install.png` | `etoolmanager install git` |
